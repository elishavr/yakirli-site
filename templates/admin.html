כניסה לנתוני האתר

הנתונים נאספים בשירות GoatCounter, בלי עוגיות ובלי מידע מזהה על הגולשים. כדי לראות אותם כאן, הדביקו את מפתח הגישה (API key) של החשבון.

המפתח נשמר רק בדפדפן שלכם, במכשיר הזה. הוא לא נשלח לשום מקום חוץ מ־GoatCounter.

החלק הראשון בכתובת: {{analytics_code}}.goatcounter.com

איך מקבלים מפתח גישה? (פעם אחת בלבד)
  1. נכנסים ל־goatcounter.com ופותחים חשבון חינמי. בשדה הקוד כותבים {{analytics_code}}.
  2. אחרי הכניסה: בתפריט העליון בוחרים את שם המשתמש ← API.
  3. לוחצים New API key, נותנים שם (למשל "האזור האישי"), מסמנים הרשאה לקריאת נתונים (Read statistics) ושומרים.
  4. מעתיקים את המפתח, ומדביקים אותו כאן.

אפשר תמיד לראות את הנתונים גם ישירות בלוח הבקרה של GoatCounter.
