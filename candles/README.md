# פרויקט הנרות של יקיר לי

התיקייה כוללת את החבילה שמוגשת בפועל (`live`), את הממשק שפעל בכתובת `/candles/` בנובמבר 2026 (`web`), את גרסת 2025 (`web-2025`) ואת קוד השרת מהמאגר של שיר (`backend`). כל ממשק עומד בפני עצמו. גרסת האתר הפעילה משתמשת ב־Firestore ישירות.

קוד הממשק מבוסס על [המאגר של שיר](https://github.com/ShirShevach/yakirLi-web/commit/d5a39b3588e1e72f97059c93604cc1c64849970a). קובצי המקור ממפות המקור של כל גרסה הותאמו לקוד שהוגש בפועל, לרבות העיצוב. נתוני הדוגמה עם פרטי קשר הוסרו. [מאגר השרת המקורי](https://github.com/ShirShevach/yakirLi-candles-backend/commit/c0dca40f38f5c55bbf7018e2d69f6217cf564631).

## הפעלה מקומית

בתיקיית הממשק הרצויה מעתיקים את `.env.example` אל `.env.local`, ממלאים את הגדרות אפליקציית הווב של Firebase ומריצים `npm ci` ואחריו `npm start`. ליצירת אתר סטטי מריצים `npm run build`. שרת ה־Node המקורי מקבל את כתובת MongoDB ממשתנה הסביבה `MONGODB_URI`.

קובצי המקור והנכסים מאפשרים בנייה של הממשק. רשומות המשפחות וההדלקות נשמרות בנפרד בפרויקט Firestore. בניית האתר הראשי פועלת בנפרד מתיקייה זו.

## החבילה המוגשת (`live`)

`live` היא החבילה שהוגשה בכתובת `yakirli.org/candles/` ב־19.11.2026, כמו שהיא, בלי קובצי מפות המקור. `build.py` מעתיק אותה אל `dist/candles/`, כך שכל פריסה של האתר כוללת את הנרות באותה כתובת. לעדכון הנרות בונים את `web` ומחליפים את תוכן `live` בתוכן `build`. הנתיבים בחבילה מתחילים ב־`/candles/`, ולכן היא עובדת רק כשהאתר בשורש הדומיין (לא בתצוגה של GitHub Pages).
