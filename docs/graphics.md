## שיתוף ולוגו

- `og-he.png` ו־`og-en.png`: 1200×630, לוגו מקורי, שם העמותה והסלוגן. מקור וקטורי לעריכה נשמר ב־`og-he.svg` וב־`og-en.svg`; תמונת הלוגו המקורית מקושרת ממנו.
- `og:image` הוא URL מוחלט לפי `--site-url`, עם שפה מתאימה, מידות ו־alt. זה פועל הן בקידומת GitHub Pages והן בדומיין העתידי. נוסף `summary_large_image`.
- PNG הוא ייצוא מדויק מה־SVG באמצעות Chromium וגופן Assistant. הגופן לא נארז ולא נוספה תלות לאתר. עריכת SVG וייצוא חוזר דורשים התקנת Assistant בכלי הגרפי.
- נבדקו `assets/logo-source.png` והלוגו הקיים. המקור הוא תמונת רסטר שטוחה, ללא וקטורים. `mark.png` והפביקונים נשמרו: לא בוצע שרטוט מחדש שעלול לשנות את הלוגו. לקבלת SVG נאמן נדרש הקובץ המקורי מהמעצב. זהו הסעיף שלא הושלם כווקטור.
