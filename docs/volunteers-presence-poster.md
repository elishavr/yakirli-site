# כרזה בעמוד המתנדבים

לבקשת פיני שולבה הכרזה עם האבנים והמשפט על נוכחות בעמוד המתנדבים בעברית, לצד ההסבר למי מיועד המיזם. הכרזה כוללת את הלוגו שצירף וללא לבבות. מוצגת במלואה ללא חיתוך, עם טקסט חלופי וטעינה עצלה. קובץ SVG עוטף תמונת WebP, ללא שינוי בתוכן התמונה. הכותרת הראשית והטפסים לא שונו.

בדיקות: בנייה עם קידומת GitHub Pages ולכתובת שורש, בדיקת קישורים ובדיקת מיפוי טפסים. צילומי לפני ואחרי בדסקטופ ובנייד נאספים בהרצת Review screenshots של בקשת השינוי.
