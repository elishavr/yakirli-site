## הפעלת התראה אוטומטית בכל מילוי Google Form
חיבור למאגר GitHub ולדרייב מאפשר שינוי קישורים וקבצי Sheets, אך לא שינוי הגדרות Google Forms או התקנת טריגר Apps Script בחשבון Google דרך הכלים הזמינים. לכן הפעלת התראות **לא בוצעה**.

לכל אחד מגיליונות *תגובות* המקושרים לטפסים:
1. פותחים את Google Sheets של תשובות הטופס, ובוחרים **תוספים → Apps Script**.
2. מדביקים את הקוד מ־[`tools/google-form-email-notify.gs`](../tools/google-form-email-notify.gs) ושומרים.
3. בצד בוחרים **טריגרים / Triggers → Add Trigger**:
   - Function: `yakirLiOnFormSubmit`
   - Event source: **From spreadsheet**
   - Event type: **On form submit**
4. נכנסים ב־Apps Script אל **Project Settings → Script properties**, מוסיפים מאפיין בשם `ALERT_EMAIL` ואת כתובת המייל הפרטית שלך כערך. כך היא לא מתפרסמת בקוד האתר.
5. מאשרים את הרשאות Google להרצת הטריגר.
6. מבצעים הגשת בדיקה אמיתית מהקישור הציבורי של הטופס. בודקים שהתווספה שורה לגיליון ושהתקבל מייל בכותרת "טופס חדש מהאתר - [שם הטופס]", עם שדות מסודרים מיושרים לימין.
7. חוזרים על שלבים 1–6 בכל גיליון תגובות רלוונטי. אם לטופס אין גיליון תגובות מקושר, יש להוסיף אחד דרך לשונית Responses בטופס.

**זהירות:** הגשות אמיתיות עשויות להכיל מידע רגיש על אבל ואובדן. אין לשתף את הגיליונות או מיילי ההתראה עם חשבונות נוספים ללא צורך, ויש לקבוע מדיניות שמירה ומחיקה. אין לפרסם כתובת מייל אישית בקוד הדפדפן.
