## התקנת התראה אוטומטית על כל מילוי Google Form

חובה לבצע עבור **כל גיליון תגובות המקושר לטופס הפעיל**:

1. לפתוח את גיליון התשובות ב־Google Sheets. אין לבצע בדיקה עם תשובות רגישות קיימות.
2. תפריט **תוספים (Extensions) → Apps Script**. להעתיק את התוכן של [`tools/google-form-email-notify.gs`](../tools/google-form-email-notify.gs), לשמור.
3. **Project Settings → Script properties → Add script property**: בשם `ALERT_EMAIL`, הערך הוא **כתובת המייל הפרטית שהמשתמש כבר אישר**. הערך חייב להישאר בסקריפט הפרטי, **לא** ב־GitHub/קוד האתר.
4. מתוך עורך Apps Script לבחור `yakirLiInstallTrigger` וללחוץ **Run**. לאשר הרשאות נדרשות. הפונקציה מוודאת שאין טריגר כפול ומתקינה `From spreadsheet → On form submit`.
5. לפתוח את **הקישור הציבורי לטופס**, למלא שדות בדיקה בלבד ולשלוח.
6. לוודא שלושת הדברים: (א) ההגשה התקבלה בהצלחה בדפדפן, (ב) שורת תשובות חדשה נוספה בגיליון, (ג) במייל הפרטי התקבלה הודעה שכותרתה `טופס חדש מהאתר - <שם הטופס>`, הכוללת את שם הטופס ואת **כל השאלות והתשובות בטבלה מימין לשמאל**.
7. בדיקת `yakirLiSendDesignTest` שולחת רק מייל סינתטי; אינה בודקת שהטריגר פועל. בדיקה אמיתית היא סעיף 5.
8. לבדוק הודעות בספאם, מספר טריגרים, `Executions` ב־Apps Script, ושהחשבון בעל הסקריפט רשאי לשלוח הודעות.
9. לתעד תוצאה פרטית ללא פרטי משפחה. אין לפתוח הרשאות ציבוריות לגיליון.

## הפעלת טופס פנייה כללית והזמנת הרצאה

הפתרון המתוכנן הוא `tools/site-forms-backend.gs`. הוא דורש חשבון Google מורשה ופריסה כ־Google Apps Script Web App:

1. לשמור את הסקריפט בפרויקט Apps Script של העמותה.
2. להגדיר `ALERT_EMAIL` ככתובת המייל הפרטית, `CC_EMAIL` רק אם רוצים עותק נוסף.
3. להריץ `testSubmission()` על **נתוני בדיקה בלבד**, ולוודא יצירת גיליון פרטי, שורה חדשה ומייל HTML.
4. לפרוס כ־Web App; כדי לאפשר הגשה מאנשים שאינם מחוברים לגוגל, תידרש גישה ציבורית ל־**נקודת הקליטה בלבד**, ולא לגיליון. יש לשקול הגנה מספאם ומכסות.
5. לבדוק בקשה אמיתית מתוך האתר. **קריאת `fetch` ל־Apps Script עשויה להיכשל ב־CORS/redirect למרות שמידע נשמר**; אל תפרסמו endpoint בייצור בלי בדיקה אמינה המאשרת קבלה, ובלי מניעת כפילויות.
6. רק אחרי שהבדיקה הצליחה: `python3 build.py --forms-endpoint 'https://script.google.com/macros/s/.../exec'`, או להגדיר `YAKIRLI_FORMS_ENDPOINT` בסביבת הפריסה. `build.py` דוחה כתובות לא־תואמות; מחרוזת ריקה משאירה גיבוי `mailto:`.
7. להגיש פנייה סינתטית משני סוגי הטפסים, בשתי השפות, לוודא תאריך/נושא/הודעה/מייל, שורה בגיליון והתראה למייל הפרטי.

**אין לטעון שהטפסים האלה שולחים אוטומטית כעת.** ה־endpoint עדיין אינו מוגדר.

## תיקונים ובדיקות סטטיות
- `python3 build.py --base /yakirli-site`
- `python3 tools/check_links.py --base /yakirli-site`
- `python3 tools/check_forms.py`
- `python3 build.py` לבנייה לדומיין שורש.

הבודק הסטטי מאמת נוכחות קישורים ידועים, שדות חובה וקוד התראה; הוא **אינו** מאמת שמסירה התרחשה בשירות חיצוני.

## השלמות נדרשות
- גישה/אישור בעל החשבון להפעלת Apps Script וטריגרים לכל אחד מחמשת גיליונות התשובות.
- בדיקת שליחה אמיתית והגעה לתיבה הפרטית עבור כל סוג פנייה.
- אימות טופסי משפחות וסבים ותנאי הצטרפות לדיוור לפי החלטת העמותה.
- טיפול סופי בתוכן מדיניות הפרטיות, בהשקפת המידע הרגיש, ובמחזור חיי הנתונים.
