# תמונות בסגנון צילום · 9.10.2026

לבקשת אלישב, שמונה תמונות מקוריות שנוצרו ב־AI מחליפות את איורי ההירו הגדולים. ענף `codex/photographic-images`, בסיס `main` בקומיט `dec7262`. העבודות הקודמות של קלוד ושל Codex נשמרות.

הרפרנס הוא האווירה השקטה, האור הטבעי ומסגור התמונות באתר [מ.ש.ה](https://moshe.org.il/). לא הועתקו תמונות, סצנות, אנשים, טקסטים או נכסי מותג מהאתר. אלה תמונות אווירה להמחשה, ולא תיעוד של פעילות העמותה או של מקום השייך לה. אין בהן אנשים, פנים, פרטים מזהים או לוגואים. תמונות דסי ופיני הקיימות נשמרו.

## השילוב

- מסגור `cover`, יחס 4:3 במחשב ו־16:10 בהירו בנייד. גם ההירו הדקורטיבי בעמודים ללא `.ph` משתמש בתמונות.
- תמונת ההירו המתאימה נטענת מוקדם בעזרת `preload` עם עדיפות גבוהה. עמודי נגישות ופרטיות אינם טוענים תמונת הירו. טעינת ה־AVIF המוקדמת מדלגת בדפדפן שאינו תומך בפורמט; ה־CSS כולל חלופת WebP.
- בוטלה אנימציית הכניסה של מסגרת התמונה כדי שהתמונה תופיע מיד. יתר אנימציות האתר ומצב הפחתת תנועה נשמרו.
- הכיתובים בסוגריים נשמרו בדיוק בהתאם ל־AGENTS.md, עם רקע אטום לקריאות. תיאורי `aria-label` ב־14 מקומות התמונה עודכנו לתיאור הסצנה המוצגת ולציון היותה הדמיה שנוצרה ב־AI.
- מבנה העמודים, הטקסט הגלוי, TODO, פרטי הקשר, הטפסים, האייקונים, הלוגו ותמונות השיתוף לא שונו. האיורים הווקטוריים והמחולל שלהם נשמרו כנכסים קיימים; הפעלת המחולל אינה משחזרת את התמונות החדשות.

## נבדק בפועל

- בנייה עם `/yakirli-site`, ואחריה בנייה לשורש; בודק הקישורים בשתיהן: 36 עמודים, אפס שגיאות. 404, מפת האתר וקובץ robots קיימים.
- כל 37 קובצי HTML עברו html-validate; CSS עבר בדיקת תחביר עם css-tree.
- השוואת כל 36 קובצי התוכן לבסיס: זהים לאחר נטרול תיאורי `aria-label`. הכיתובים בסוגריים, המקטעים והטקסט הגלוי נשמרו.
- Playwright ו־axe-core: כל 36 העמודים ב־1440×1000 וב־360×800; 72 צילומי אחרי. אפס הפרות axe, גלישה אופקית, תמונות שבורות, שגיאות JS או שדות ללא תווית. Assistant נטען ממטמון מקומי בצילומים אלה.
- בדיקה חזותית של החיתוך והכיתוב בתמונות ההירו במחשב ובנייד, כולל בית בשתי השפות, תמיכה, פעילות ציבורית, ידע, הנצחה, מדיה, קשר ותרומה.
- Lighthouse 12.8.2 במצב מובייל: בית בעברית 93 ביצועים / 100 נגישות; עמוד הסבים והסבתות בעברית 91 / 100. הבדיקה מקומית, עם Assistant ממטמון ו־gzip לתוכן טקסטואלי. תמיכת gzip בשרת GitHub Pages אומתה בבקשת HTTP לקובץ ה־CSS. זו אינה מדידת ביצועים של האתר החי או של רשת סלולרית אמיתית.
- צילומי לפני ואחרי של כל 36 העמודים בשני הרוחבים מופקים ב־Review screenshots. הארכיון ב־PR כולל 144 תמונות ושני קובצי תוצאות, ללא צילומי בדיקה בריפו.
